## 👋 About

I run **[Solrus](https://solrus.pro)**, an independent technical studio based in Algiers, working with
clients wherever they are. We build the unglamorous, load-bearing software that businesses actually run on —
ERP systems, back-office tools for accounting firms, manufacturers, HR and childcare, order and reporting
automations — and the AI layer on top of it.

Most of my days: FastAPI and Next.js in the morning, a Flutter screen or an n8n flow after lunch, and
Claude Code open the whole time.

## 🧭 How I build

- **The data stays where it belongs.** The model can be anywhere; the names, phones and IDs don't travel with the prompt.
- **A client should be able to run the system without me.** Docs and a clean `compliance/` folder are deliverables, not extras.
- **Boring architecture, honest estimates**, and one chokepoint for anything that leaves the server.
